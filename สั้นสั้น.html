ตัวอย่างคำบรรยายภาษาไทย

สร้างและแก้ไขคำบรรยาย

เลือกวิธีใส่ซับ: นำเข้าไฟล์ SRT หรือเชื่อม API ถอดเสียง (ต้องมีเซิร์ฟเวอร์ของคุณเอง)

การถอดเสียงจากไฟล์วิดีโอเป็นซับอัตโนมัติต้องใช้โมเดล Speech-to-Text ผ่าน API/Backend ที่มีคีย์ส่วนตัว ไม่ควรฝังคีย์ API ไว้ใน HTML เพราะผู้อื่นสามารถขโมยได้ รุ่นนี้รองรับการนำเข้า แก้ไข และส่งออก SRT ได้จริง
